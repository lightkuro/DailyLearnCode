## 1.0.0 — 2026-11-16

### First public release
- **Daily set:** a starter quiz, easy, medium and hard coding problems, and a software-engineering quiz, scored out
  of 20. Coding problems run in Python, Java or C++ right in your browser, with hints, editorials and alternative
  solutions. Ships with a week of sample sets; when there's no set for today, an earlier one comes back as a
  classic.
- **Unlimited:** keep drawing questions and problems from every set, or rounds of software-engineering interview
  questions on the topics you pick.
- **Detective:** five short snippets per round, each hiding one bug: pick what's wrong, flag the bad line or write
  the missing one. A Design file swaps code for system design docs.
- **Learn:** a crash-course page for every topic the questions cover, plus language crash courses (Python, Java, C++,
  JavaScript/TypeScript/React and SQL). Diagrams, code in your language, full-text search, and a contents sheet for
  jumping between sections on a phone.
- **Stats:** scores, streaks, per-topic accuracy and the mistakes worth reviewing.
- Progress stays in your browser. Export a backup any time, or sync to your own Google Drive where the site has it
  set up.
